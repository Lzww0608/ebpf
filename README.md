## 入门级练习

- [ ] 1. 监控所有 rm 删除文件操作，记录删除的文件路径和进程信息
- [ ] 2. 统计系统中所有进程的 TCP 连接建立次数
- [ ] 3. 监控进程，记录被杀死的进程信息

## 进阶级练习

- [ ] 1. 开发一个慢 SQL 监控工具：监控 MySQL 进程的 write 调用，提取执行时间超过 100ms 的 SQL
- [ ] 2. 开发一个端口扫描检测工具：监控短时间内访问大量端口的 IP 地址
- [ ] 3. 开发一个容器资源监控工具：基于 cgroup eBPF 统计每个容器的 CPU、内存、IO 使用情况

## 高级练习

- [ ] 1. 开发一个基于 eBPF 的应用性能监控工具，自动统计接口调用次数、延迟、错误率
- [ ] 2. 开发一个轻量级入侵检测系统，监控异常系统调用、敏感文件访问、权限提升行为
- [ ] 3. 开发一个基于 XDP 的 DDoS 防护工具，自动拦截攻击流量
