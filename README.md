## 入门级练习
[]1. 监控所有rm删除文件操作，记录删除的文件路径和进程信息
[]2. 统计系统中所有进程的TCP连接建立次数
[]3. 监控进程，记录被杀死的进程信息

## 进阶级练习
[]1. 开发一个慢SQL监控工具：监控MySQL进程的write调用，提取执行时间超过100ms的SQL
[]2. 开发一个端口扫描检测工具：监控短时间内访问大量端口的IP地址
[]3. 开发一个容器资源监控工具：基于cgroup eBPF统计每个容器的CPU、内存、IO使用情况

## 高级练习
[]1. 开发一个基于eBPF的应用性能监控工具，自动统计接口调用次数、延迟、错误率
[]2. 开发一个轻量级入侵检测系统，监控异常系统调用、敏感文件访问、权限提升行为
[]3. 开发一个基于XDP的DDoS防护工具，自动拦截攻击流量
